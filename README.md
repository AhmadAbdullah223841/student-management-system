# 🎓 Student Management System

A modern **Student Management System** built with **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**. This project allows users to securely manage student records with authentication and a clean user interface.

---

## 🚀 Features

* 🔐 User Registration & Login
* 🔒 Secure Password Hashing
* 🔑 Forgot Password with Email OTP Verification
* 👤 User Dashboard
* ➕ Add Student Records
* 📋 View Student Records
* ✏️ Edit Student Information
* 🗑️ Delete Student Records
* 🔍 Live Search
* 📄 Pagination
* 🖼️ Student Image Upload
* 👤 Each user can access only their own student records
* 🎨 Responsive and Modern UI Design

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/AhmadAbdullah223841/student-management-system.git
```

2. Move the project into your **htdocs** folder.

3. Create a MySQL database.

4. Import the SQL file.

5. Update your database credentials inside **db.php**.

6. Start **Apache** and **MySQL** from XAMPP.

7. Open your browser and visit:

```text
http://localhost/Alice
```
